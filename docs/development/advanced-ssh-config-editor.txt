Below is a complete, modular Python + GTK4 + Libadwaita package (ssh_workbench)
designed according to GNOME HIG. Name to be changed. SSHWORKBENCH is the name of another app.

  - Cross-platform Gtk.Widget (SshConfigWorkbench(Adw.Bin)): Packs directly into
    any Gtk.Paned, Gtk.Box, Adw.NavigationSplitView, or Adw.TabView on Linux,
    Windows, and macOS.
  - Standalone Desktop App (Adw.Application): Wraps that exact widget in an
    Adw.ApplicationWindow + Adw.HeaderBar with Adw.StyleManager
    Light/Dark/System theme switching.
  - GNOME HIG & Libadwaita Widgets: Uses Adw.Bin, Adw.ToolbarView,
    Adw.HeaderBar, Adw.ViewStack + Adw.ViewSwitcher, Gtk.ListBox (.boxed-list),
    Adw.ActionRow, Adw.ExpanderRow, Adw.Banner, Adw.ToastOverlay, Gtk.Paned,
    Gtk.SearchEntry, Gtk.FileDialog, Adw.Dialog, and native Gtk.DragSource /
    Gtk.DropTarget for drag-and-drop reordering.
  - Pure Python OpenSSH Engine: Comment-safe parser (no leaking # lines or
    inline comments into directive rows), real ~/.ssh/config & disk Include glob
    loading, atomic save with .bak backup + 0600 permissions, and live
    comparison against your system's ssh -G binary.

def new_id(prefix: str = "id") -> str:
    return f"{prefix}_{uuid.uuid4().hex[:10]}"


def canonicalize_key(key: str) -> str:
    return CANONICAL_KEYWORD_MAP.get(key.lower(), key)

    key: str = ""
    value: str = ""

@dataclass

@dataclass
class SimContext:
    raw_target: str = "web1.prod.internal"
    cli_port: str = ""
    cli_user: str = ""
    local_user: str = field(default_factory=lambda: os.environ.get("USER") or os.environ.get("USERNAME") or "alice")
    local_host: str = field(default_factory=lambda: os.uname().nodename.split(".")[0] if hasattr(os, "uname") else "workstation")
    force_final: bool = False
    exec_result: bool = True
    base_dir: Path = field(default_factory=lambda: Path.home() / ".ssh")

    @property
    def target_parts(self) -> tuple[str, str]:
        raw = self.raw_target.strip() or "localhost"
        if "@" in raw:
            user_part, host_part = raw.rsplit("@", 1)
            return user_part, host_part or "localhost"
        return "", raw

    @property
    def original_host(self) -> str:
        return self.target_parts[1]

    @property
    def effective_cli_user(self) -> str:
        return self.cli_user.strip() or self.target_parts[0]

_LINE_KV_RE = re.compile(r"^([A-Za-z0-9_]+)(?:\s*=\s*|\s+)(.*)$")


def strip_inline_comment(raw_val: str) -> tuple[str, str]:
    in_quotes = False
    for i, ch in enumerate(raw_val):
        if ch == '"':
            in_quotes = not in_quotes
        elif not in_quotes and ch == "#" and (i == 0 or raw_val[i - 1].isspace()):
            return raw_val[:i].rstrip(), raw_val[i:].strip()
    return raw_val.strip(), ""


def parse_config(raw: str) -> ParsedConfig:
    cleaned = raw.lstrip("\ufeff").replace("\r\n", "\n").replace("\r", "\n")
    lines = cleaned.split("\n")
    blocks: list[ConfigBlock] = []
    current_block: ConfigBlock | None = None
    pending_comments: list[str] = []

    def ensure_global() -> ConfigBlock:
        nonlocal current_block, pending_comments
        if current_block is None:
            current_block = ConfigBlock(
                kind="global",
                patterns="",
                raw_leading_comments=pending_comments,
            )
            pending_comments = []
            blocks.append(current_block)
        return current_block

    for raw_line in lines:
        trimmed = raw_line.strip()
        if not trimmed:
            if pending_comments and pending_comments[-1] != "":
                pending_comments.append("")
            continue

        if trimmed.startswith("# [disabled] "):
            inner = trimmed[len("# [disabled] ") :].strip()
            m_dis = _LINE_KV_RE.match(inner)
            if m_dis:
                d_key = m_dis.group(1).lower()
                d_val, inline_c = strip_inline_comment(m_dis.group(2))
                if d_key in ("host", "match"):
                    current_block = ConfigBlock(
                        kind=d_key,  # type: ignore[arg-type]
                        patterns=d_val,
                        inline_comment=inline_c,
                        raw_leading_comments=pending_comments,
                        disabled=True,
                    )
                    pending_comments = []
                    blocks.append(current_block)
                    continue
                if current_block is not None and current_block.disabled:
                    current_block.directives.append(
                        Directive(
                            key=canonicalize_key(m_dis.group(1)),
                            value=d_val,
                            inline_comment=inline_c,
                            raw_leading_comments=pending_comments,
                        )
                    )
                    pending_comments = []
                    continue

        if trimmed.startswith("#"):
            pending_comments.append(trimmed)
            continue

        m = _LINE_KV_RE.match(trimmed)
        if m:
            key, raw_rest = m.group(1), m.group(2)
        else:
            key, raw_rest = trimmed, ""

        val, inline_c = strip_inline_comment(raw_rest)
        lower_key = key.lower()

        if lower_key in ("host", "match"):
            current_block = ConfigBlock(
                kind=lower_key,  # type: ignore[arg-type]
                patterns=val,
                inline_comment=inline_c,
                raw_leading_comments=pending_comments,
            )
            pending_comments = []
            blocks.append(current_block)
        else:
            blk = ensure_global()
            blk.directives.append(
                Directive(
                    key=canonicalize_key(key),
                    value=val,
                    inline_comment=inline_c,
                    raw_leading_comments=pending_comments,
                )
            )
            pending_comments = []

    if pending_comments and pending_comments[-1] == "":
        pending_comments.pop()

    return ParsedConfig(blocks=blocks, trailing_comments=pending_comments)


def serialize_config(blocks: list[ConfigBlock], trailing_comments: list[str] | None = None) -> str:
    out: list[str] = []
    for idx, blk in enumerate(blocks):
        if idx > 0:
            out.append("")
        out.extend(blk.raw_leading_comments)
        if blk.note.strip():
            for line in blk.note.splitlines():
                if line.strip():
                    out.append(f"# {line.strip()}")

        prefix = "# [disabled] " if blk.disabled else ""
        tail = f" {blk.inline_comment}" if blk.inline_comment else ""
        if blk.kind == "host":
            out.append(f"{prefix}Host {blk.patterns.strip() or '*'}{tail}")
        elif blk.kind == "match":
            out.append(f"{prefix}Match {blk.patterns.strip() or 'all'}{tail}")
        elif blk.disabled:
            out.append("# [disabled global section]")

        indent = "" if blk.kind == "global" else "  "
        for d in blk.directives:
            if not d.key.strip():
                continue
            for c in d.raw_leading_comments:
                out.append("" if c == "" else f"{indent}{c}")
            d_tail = f" {d.inline_comment}" if d.inline_comment else ""
            out.append(f"{prefix}{indent}{d.key.strip()} {d.value}{d_tail}".rstrip())

    if trailing_comments:
        out.append("")
        out.extend(trailing_comments)

    text = "\n".join(out)
    text = re.sub(r"\n{3,}", "\n\n", text)
    return text + "\n"


def tokenize_quoted(text: str) -> list[str]:
    try:
        return shlex.split(text)
    except ValueError:
        return text.split()


def match_pattern_list(target: str, patterns: list[str]) -> tuple[bool, str]:
    got_positive = False
    for raw_pat in patterns:
        if not raw_pat:
            continue
        negated = raw_pat.startswith("!")
        pat = raw_pat[1:] if negated else raw_pat
        if not pat:
            continue
        matched = fnmatch.fnmatchcase(target, pat)
        if negated:
            if matched:
                return False, f'Negated by "{raw_pat}"'
        elif matched:
            got_positive = True

    if got_positive:
        return True, "Matched positive pattern"
    if patterns and all(p.startswith("!") for p in patterns):
        return False, 'Only negated patterns present (OpenSSH requires a positive pattern like "*")'
    return False, "No pattern matched"


def evaluate_match_criteria(
    criteria: str,
    *,
    original_host: str,
    current_host: str,
    current_user: str,
    local_user: str,
    is_canonical_pass: bool,
    is_final_pass: bool,
    exec_result: bool,
) -> tuple[bool, str]:
    tokens = tokenize_quoted(criteria.strip())
    if not tokens:
        return False, "Empty Match criteria"

    reasons: list[str] = []
    i = 0
    while i < len(tokens):
        tok = tokens[i]
        negate = tok.startswith("!")
        if negate:
            tok = tok[1:]
        kw = tok.lower()

        if kw == "all":
            cond_ok, detail, step = True, "all", 1
        elif kw == "canonical":
            cond_ok, detail, step = is_canonical_pass, f"canonical={is_canonical_pass}", 1
        elif kw == "final":
            cond_ok, detail, step = is_final_pass, f"final={is_final_pass}", 1
        elif kw == "host":
            arg = tokens[i + 1] if i + 1 < len(tokens) else ""
            cond_ok, _ = match_pattern_list(current_host, [p for p in arg.split(",") if p])
            detail, step = f"host({current_host})~{arg}", 2
        elif kw == "originalhost":
            arg = tokens[i + 1] if i + 1 < len(tokens) else ""
            cond_ok, _ = match_pattern_list(original_host, [p for p in arg.split(",") if p])
            detail, step = f"originalhost({original_host})~{arg}", 2
        elif kw == "user":
            arg = tokens[i + 1] if i + 1 < len(tokens) else ""
            cond_ok, _ = match_pattern_list(current_user, [p for p in arg.split(",") if p])
            detail, step = f"user({current_user})~{arg}", 2
        elif kw == "localuser":
            arg = tokens[i + 1] if i + 1 < len(tokens) else ""
            cond_ok, _ = match_pattern_list(local_user, [p for p in arg.split(",") if p])
            detail, step = f"localuser({local_user})~{arg}", 2
        elif kw == "exec":
            arg = tokens[i + 1] if i + 1 < len(tokens) else ""
            cond_ok = exec_result
            detail, step = f'exec("{arg}") -> {"exit 0" if exec_result else "exit 1"}', 2
        else:
            has_arg = i + 1 < len(tokens) and tokens[i + 1].lower() not in {"all", "canonical", "final"}
            cond_ok = False
            detail = f"{kw} (not evaluated)"
            step = 2 if has_arg else 1

        if negate:
            cond_ok = not cond_ok
            detail = f"!{detail}"
        reasons.append(f"{detail}: {'yes' if cond_ok else 'no'}")
        if not cond_ok:
            return False, ", ".join(reasons)
        i += step

    return True, ", ".join(reasons)


def expand_tokens(val: str, ctx: dict[str, str]) -> str:
    if "%" not in val:
        return val

    def _sub(m: re.Match[str]) -> str:
        c = m.group(1)
        return ctx.get(c, m.group(0))

    return re.sub(r"%([%CdhikLlnpru])", _sub, val)


def _expand_include_paths(pattern: str, base_dir: Path) -> list[Path]:
    paths: list[Path] = []
    for raw_pat in tokenize_quoted(pattern):
        p = Path(raw_pat).expanduser()
        if not p.is_absolute():
            p = base_dir / raw_pat
        parent = p.parent
        name_pat = p.name
        if "*" in str(p) or "?" in str(p):
            try:
                if "*" in str(parent) or "?" in str(parent):
                    matches = sorted(Path("/").glob(str(p).lstrip("/")) if p.is_absolute() else base_dir.glob(raw_pat))
                elif parent.exists():
                    matches = sorted(parent.glob(name_pat))
                else:
                    matches = []
                paths.extend(m for m in matches if m.is_file())
            except OSError:
                pass
        elif p.is_file():
            paths.append(p)
    return paths


def resolve_config(
    blocks: list[ConfigBlock],
    sim: SimContext,
    virtual_includes: dict[str, str] | None = None,
    read_disk_includes: bool = True,
) -> ResolutionResult:
    virtual_includes = virtual_includes or {}
    options: dict[str, EffectiveOption] = {}
    shadowed: dict[str, list[dict[str, str]]] = {}
    block_status: dict[str, tuple[bool, str, list[str]]] = {}
    dir_status: dict[str, tuple[str, str]] = {}
    trace: list[TraceEntry] = []
    seen_includes: list[str] = []
    resolved_include_files: list[str] = []

    if sim.cli_port.strip():
        options["port"] = EffectiveOption(
            key="Port",
            value=sim.cli_port.strip(),
            source="CLI (-p flag)",
            is_cli=True,
        )
        trace.append(TraceEntry("pass", f"CLI Override: Port = {sim.cli_port.strip()}", "Command-line port takes highest precedence."))

    if sim.effective_cli_user:
        options["user"] = EffectiveOption(
            key="User",
            value=sim.effective_cli_user,
            source="CLI (-l / user@)",
            is_cli=True,
        )
        trace.append(TraceEntry("pass", f"CLI Override: User = {sim.effective_cli_user}", "Command-line user takes highest precedence."))

    def run_pass(
        label: str,
        host_for_host_block: str,
        current_host: str,
        is_canonical: bool,
        is_final: bool,
    ) -> None:
        trace.append(
            TraceEntry(
                "pass",
                label,
                f'Host target "{host_for_host_block}", Match host "{current_host}"',
            )
        )

        def walk_blocks(blk_list: list[ConfigBlock], prefix_label: str = "", depth: int = 0) -> None:
            for idx, blk in enumerate(blk_list):
                blk_num = prefix_label or f"#{idx + 1}"
                warnings: list[str] = []

                if blk.disabled:
                    if not prefix_label:
                        block_status[blk.id] = (False, "Disabled (commented out)", warnings)
                    for d in blk.directives:
                        dir_status[d.id] = ("inactive", "Block disabled")
                    trace.append(TraceEntry("skip", f"Block {blk_num} ({blk.kind}) — Disabled", "Skipped because block is disabled."))
                    continue

                if blk.kind == "global":
                    matched, reason = True, "Top-level global directive (always applies)"
                elif blk.kind == "host":
                    pats = tokenize_quoted(blk.patterns)
                    if pats == ["*"] and not prefix_label:
                        has_specific_after = any(
                            not b.disabled and b.kind == "host" and b.patterns.strip() != "*"
                            for b in blk_list[idx + 1 :]
                        )
                        if has_specific_after:
                            warnings.append(
                                'Wildcard "Host *" appears before more specific Host blocks — '
                                "OpenSSH first-match-wins will shadow matching options below."
                            )
                    if pats and all(p.startswith("!") for p in pats):
                        warnings.append('Negation-only pattern without a positive wildcard (e.g. "*") never matches in OpenSSH.')
                    matched, reason = match_pattern_list(host_for_host_block, pats)
                else:
                    cur_h = current_host
                    if "hostname" in options and isinstance(options["hostname"].value, str):
                        cur_h = options["hostname"].value.replace("%h", sim.original_host).replace("%%", "%")
                    cur_u = (
                        str(options["user"].value)
                        if "user" in options
                        else sim.local_user
                    )
                    matched, reason = evaluate_match_criteria(
                        blk.patterns,
                        original_host=sim.original_host,
                        current_host=cur_h,
                        current_user=cur_u,
                        local_user=sim.local_user,
                        is_canonical_pass=is_canonical,
                        is_final_pass=is_final,
                        exec_result=sim.exec_result,
                    )

                if not prefix_label:
                    prev = block_status.get(blk.id)
                    if prev and prev[0]:
                        block_status[blk.id] = (True, f"{prev[1]} (Pass 2: {reason})", warnings)
                    else:
                        block_status[blk.id] = (matched, reason, warnings)

                blk_label = (
                    f"{blk_num} Global"
                    if blk.kind == "global"
                    else f"{blk_num} {blk.kind.capitalize()} {blk.patterns}"
                )

                if not matched:
                    for d in blk.directives:
                        if d.id not in dir_status:
                            dir_status[d.id] = ("inactive", reason)
                    trace.append(TraceEntry("skip", f"{blk_label} — Skipped", reason))
                    continue

                trace.append(TraceEntry("match", f"{blk_label} — Matched", reason))

                for d in blk.directives:
                    if not d.key.strip():
                        continue
                    lk = d.key.lower()
                    ck = canonicalize_key(d.key)

                    if lk == "include":
                        seen_includes.append(d.value)
                        if depth >= 8:
                            dir_status[d.id] = ("include", "Max Include recursion depth reached")
                            continue

                        inc_blocks_loaded: list[tuple[str, list[ConfigBlock]]] = []
                        # Check virtual overrides first
                        for vp, vtext in sorted(virtual_includes.items()):
                            norm_pat = d.value.removeprefix("~/")
                            norm_vp = vp.removeprefix("~/")
                            if vp == d.value or fnmatch.fnmatchcase(norm_vp, norm_pat):
                                inc_blocks_loaded.append((vp, parse_config(vtext).blocks))

                        # Check real files on disk
                        if read_disk_includes:
                            for disk_p in _expand_include_paths(d.value, sim.base_dir):
                                s_p = str(disk_p)
                                if s_p not in virtual_includes:
                                    try:
                                        text = disk_p.read_text(encoding="utf-8", errors="replace")
                                        inc_blocks_loaded.append((s_p, parse_config(text).blocks))
                                    except OSError:
                                        pass

                        if inc_blocks_loaded:
                            dir_status[d.id] = ("include", f"Included {len(inc_blocks_loaded)} file(s)")
                            for inc_name, inc_blks in inc_blocks_loaded:
                                if inc_name not in resolved_include_files:
                                    resolved_include_files.append(inc_name)
                                trace.append(TraceEntry("pass", f"Include {inc_name}", f'Matched by "{d.value}"'))
                                walk_blocks(inc_blks, f"Include({Path(inc_name).name})", depth + 1)
                        else:
                            dir_status[d.id] = ("include", "No matching include files found")
                            trace.append(TraceEntry("warn", f"Include {d.value}", "No matching files found on disk or virtual includes."))
                        continue

                    if lk in ACCUMULATING_OPTIONS:
                        if lk not in options:
                            options[lk] = EffectiveOption(
                                key=ck,
                                value=[],
                                source=blk_label,
                                block_id=blk.id,
                                dir_id=d.id,
                                is_accumulated=True,
                            )
                        entry = options[lk]
                        assert isinstance(entry.value, list)
                        if not any(s["dir_id"] == d.id for s in entry.sources):
                            if lk == "sendenv" and d.value.startswith("-"):
                                rm_pat = d.value[1:]
                                entry.value = [v for v in entry.value if not fnmatch.fnmatchcase(v, rm_pat)]
                            else:
                                entry.value.append(d.value)
                            entry.sources.append(
                                {"label": blk_label, "block_id": blk.id, "dir_id": d.id, "value": d.value}
                            )
                        dir_status[d.id] = ("accumulated", f"Appended (#{len(entry.value)})")
                        continue

                    if lk not in options:
                        options[lk] = EffectiveOption(
                            key=ck,
                            value=d.value,
                            source=blk_label,
                            block_id=blk.id,
                            dir_id=d.id,
                        )
                        dir_status[d.id] = ("applied", "First match wins (active)")
                    else:
                        winner = options[lk]
                        if winner.dir_id == d.id:
                            continue
                        if winner.is_cli:
                            dir_status[d.id] = ("cli", f"Overridden by {winner.source}")
                        else:
                            dir_status[d.id] = ("shadowed", f"Shadowed by {winner.source}")
                        shadowed.setdefault(lk, []).append(
                            {"value": d.value, "source": blk_label, "block_id": blk.id, "dir_id": d.id}
                        )

        walk_blocks(blocks)

    # Pass 1
    run_pass("Pass 1: Initial Configuration Scan", sim.original_host, sim.original_host, False, False)

    # Pass 2 (Canonical / Final)
    canon_setting = str(options["canonicalizehostname"].value).lower() if "canonicalizehostname" in options else "no"
    canon_domains = str(options["canonicaldomains"].value).split() if "canonicaldomains" in options else []
    try:
        max_dots = int(str(options["canonicalizemaxdots"].value)) if "canonicalizemaxdots" in options else 1
    except ValueError:
        max_dots = 1
    dot_count = sim.original_host.count(".")
    has_match_canon_or_final = any(
        not b.disabled and b.kind == "match" and re.search(r"\b(canonical|final)\b", b.patterns, re.IGNORECASE)
        for b in blocks
    )

    eff_host_p1 = sim.original_host
    did_canonicalize = False
    if canon_setting in ("yes", "always") and canon_domains and dot_count <= max_dots and "hostname" not in options:
        eff_host_p1 = f"{sim.original_host}.{canon_domains[0]}"
        did_canonicalize = True

    if sim.force_final or did_canonicalize or has_match_canon_or_final:
        p2_label = (
            f"Pass 2: Canonicalized ({sim.original_host} -> {eff_host_p1})"
            if did_canonicalize
            else "Pass 2: Final / Canonical Re-evaluation"
        )
        cur_h_p2 = str(options["hostname"].value) if "hostname" in options else eff_host_p1
        run_pass(p2_label, eff_host_p1, cur_h_p2, did_canonicalize or sim.force_final, True)

    if "clearallforwardings" in options and str(options["clearallforwardings"].value).lower() == "yes":
        for fk in ("localforward", "remoteforward", "dynamicforward"):
            if fk in options:
                del options[fk]
                trace.append(TraceEntry("warn", "ClearAllForwardings yes", f"Cleared accumulated {canonicalize_key(fk)} rules."))

    all_effective: list[EffectiveOption] = []
    seen_keys: set[str] = set()
    for def_key, def_val in OPENSSH_DEFAULTS:
        lk = def_key.lower()
        seen_keys.add(lk)
        if lk in options:
            all_effective.append(options[lk])
        else:
            fallback: str | list[str] = copy.deepcopy(def_val)
            if lk == "hostname":
                fallback = eff_host_p1 if did_canonicalize else sim.original_host
            elif lk == "user":
                fallback = sim.local_user
            all_effective.append(
                EffectiveOption(
                    key=def_key,
                    value=fallback,
                    source="OpenSSH Default",
                    is_default=True,
                    is_accumulated=isinstance(fallback, list),
                )
            )

    for lk, opt in options.items():
        if lk not in seen_keys:
            all_effective.append(opt)

    raw_hostname = (
        str(options["hostname"].value)
        if "hostname" in options
        else (eff_host_p1 if did_canonicalize else sim.original_host)
    )
    resolved_hostname = raw_hostname.replace("%h", sim.original_host).replace("%%", "%")
    resolved_port = str(options["port"].value) if "port" in options else "22"
    resolved_user = str(options["user"].value) if "user" in options else sim.local_user
    resolved_hka = str(options["hostkeyalias"].value) if "hostkeyalias" in options else "none"
    hash_c = hashlib.sha1(f"{sim.local_host}{raw_hostname}{resolved_port}{resolved_user}".encode()).hexdigest()

    tok_ctx = {
        "%": "%",
        "h": resolved_hostname,
        "n": sim.original_host,
        "p": resolved_port,
        "r": resolved_user,
        "u": sim.local_user,
        "d": str(Path.home()),
        "L": sim.local_host,
        "l": f"{sim.local_host}.local",
        "i": str(os.getuid()) if hasattr(os, "getuid") else "1000",
        "k": resolved_hka if resolved_hka != "none" else resolved_hostname,
        "C": hash_c,
    }

    for item in all_effective:
        if item.key.lower() in TOKEN_SUPPORTED_KEYS:
            if isinstance(item.value, list):
                exp_list = [expand_tokens(v, tok_ctx) for v in item.value]
                if exp_list != item.value:
                    item.expanded_value = exp_list
            else:
                exp = expand_tokens(item.value, tok_ctx)
                if exp != item.value:
                    item.expanded_value = exp

    id_opt = options.get("identityfile")
    id_files = (
        (id_opt.expanded_value or id_opt.value)
        if id_opt
        else next(v for k, v in OPENSSH_DEFAULTS if k == "IdentityFile")
    )

    return ResolutionResult(
        effective=all_effective,
        shadowed=shadowed,
        block_status=block_status,
        dir_status=dir_status,
        trace=trace,
        seen_includes=seen_includes,
        resolved_include_files=resolved_include_files,
        summary={
            "user": resolved_user,
            "hostname": resolved_hostname,
            "port": resolved_port,
            "proxy_jump": str(options["proxyjump"].value) if "proxyjump" in options else "none",
            "proxy_command": str(options["proxycommand"].value) if "proxycommand" in options else "none",
            "identity_files": id_files,
        },
    )


def save_config_safely(path: Path, text: str, create_backup: bool = True) -> Path | None:
    path = path.expanduser()
    path.parent.mkdir(parents=True, exist_ok=True)
    backup_path: Path | None = None
    if create_backup and path.exists():
        backup_path = path.with_name(f"{path.name}.bak")
        shutil.copy2(path, backup_path)
    tmp_path = path.with_name(f".{path.name}.tmp.{os.getpid()}")
    tmp_path.write_text(text, encoding="utf-8")
    try:
        os.chmod(tmp_path, 0o600)
    except OSError:
        pass
    tmp_path.replace(path)
    return backup_path


def run_system_ssh_g(
    target: str,
    *,
    config_path: Path | None = None,
    cli_port: str = "",
    cli_user: str = "",
) -> tuple[bool, str]:
    ssh_bin = shutil.which("ssh")
    if not ssh_bin:
        return False, "`ssh` executable not found on PATH."
    cmd = [ssh_bin, "-G"]
    if config_path is not None:
        cmd.extend(["-F", str(config_path)])
    if cli_port.strip():
        cmd.extend(["-p", cli_port.strip()])
    if cli_user.strip():
        cmd.extend(["-l", cli_user.strip()])
    cmd.append(target.strip() or "localhost")
    try:
        proc = subprocess.run(cmd, capture_output=True, text=True, timeout=5)
        if proc.returncode != 0:
            return False, proc.stderr.strip() or f"ssh -G exited with code {proc.returncode}"
        return True, proc.stdout
    except Exception as exc:
        return False, str(exc)

    def _build_block_popover(self, blk: ConfigBlock, idx: int) -> Gtk.Popover:
        pop = Gtk.Popover()
        box = Gtk.Box(orientation=Gtk.Orientation.VERTICAL, spacing=2)
        box.set_margin_top(4)
        box.set_margin_bottom(4)
        box.set_margin_start(4)
        box.set_margin_end(4)
        pop.set_child(box)

        def add_item(label: str, cb, *, enabled: bool = True, destructive: bool = False) -> None:
            b = Gtk.Button(label=label)
            b.add_css_class("flat")
            if destructive:
                b.add_css_class("destructive-action")
            b.set_sensitive(enabled)
            b.connect("clicked", lambda *_: (pop.popdown(), cb()))
            box.append(b)

        add_item("Move Up", lambda: self._move_block(idx, -1), enabled=idx > 0)
        add_item("Move Down", lambda: self._move_block(idx, 1), enabled=idx < len(self.blocks) - 1)
        box.append(Gtk.Separator(orientation=Gtk.Orientation.HORIZONTAL))
        add_item("Enable Block" if blk.disabled else "Disable Block", lambda: self._toggle_block(blk))
        add_item("Add / Edit Note", lambda: self._toggle_note(blk))
        add_item("Duplicate Block", lambda: self._duplicate_block(idx))
        box.append(Gtk.Separator(orientation=Gtk.Orientation.HORIZONTAL))
        add_item("Delete Block", lambda: self._delete_block(idx), destructive=True)
        return pop

    def _render_quick_hosts(self) -> None:
        while (child := self._quick_hosts_box.get_first_child()) is not None:
            self._quick_hosts_box.remove(child)

        candidates: list[str] = []
        seen: set[str] = set()
        for b in self.blocks:
            if b.disabled or b.kind != "host":
                continue
            for pat in tokenize_quoted(b.patterns):
                if pat.startswith("!"):
                    continue
                host = f"app.{pat[2:]}" if pat.startswith("*.") else (pat if "*" not in pat and "?" not in pat else "")
                if host and host not in seen:
                    seen.add(host)
                    candidates.append(host)
        if not candidates:
            candidates = ["example.com"]

        cur_host = self._sim.original_host
        for host in candidates[:12]:
            btn = Gtk.Button(label=host)
            btn.add_css_class("pill")
            btn.add_css_class("monospace")
            if host == cur_host:
                btn.add_css_class("suggested-action")
            btn.connect("clicked", lambda *_, h=host: self._target_entry.set_text(h))
            self._quick_hosts_box.append(btn)

    # ------------------------------------------------------------------
    # Resolution Sync (In-Place Status + Right Pane)
    # ------------------------------------------------------------------
    def _update_resolution(self) -> None:
        res = resolve_config(self.blocks, self._sim, virtual_includes=self.virtual_includes)
        self._last_result = res

        matched_count = 0
        for blk in self.blocks:
            bw = self._block_widgets.get(blk.id)
            if not bw:
                continue
            card: Gtk.ListBox = bw["card"]  # type: ignore[assignment]
            pill: Gtk.Label = bw["status"]  # type: ignore[assignment]
            warn_banner: Adw.Banner = bw["warn_banner"]  # type: ignore[assignment]
            warn_row: Gtk.ListBoxRow = bw["warn_row"]  # type: ignore[assignment]

            matched, reason, warnings = res.block_status.get(blk.id, (False, "", []))
            for cls in ("ssh-pill-success", "ssh-pill-muted"):
                pill.remove_css_class(cls)

            if blk.disabled:
                card.remove_css_class("ssh-block-matched")
                pill.set_label("Disabled")
                pill.add_css_class("ssh-pill-muted")
            elif matched:
                matched_count += 1
                card.add_css_class("ssh-block-matched")
                pill.set_label("Matched")
                pill.add_css_class("ssh-pill-success")
            else:
                card.remove_css_class("ssh-block-matched")
                pill.set_label("Skipped")
                pill.add_css_class("ssh-pill-muted")
            pill.set_tooltip_text(reason)

            if warnings:
                warn_banner.set_title(warnings[0])
                warn_banner.set_revealed(True)
                warn_row.set_visible(True)
            else:
                warn_banner.set_revealed(False)
                warn_row.set_visible(False)

            for d in blk.directives:
                dw = self._dir_widgets.get(d.id)
                if not dw:
                    continue
                st_label: Gtk.Label = dw["status"]  # type: ignore[assignment]
                key_e: Gtk.Entry = dw["key"]  # type: ignore[assignment]
                val_e: Gtk.Entry = dw["val"]  # type: ignore[assignment]
                status, detail = res.dir_status.get(d.id, ("inactive", ""))

                for cls in ("ssh-pill-success", "ssh-pill-warning", "ssh-pill-accent", "ssh-pill-purple", "ssh-pill-muted"):
                    st_label.remove_css_class(cls)
                for e in (key_e, val_e):
                    e.remove_css_class("ssh-shadowed-entry")

                if status == "applied":
                    st_label.set_label("Applied")
                    st_label.add_css_class("ssh-pill-success")
                elif status == "accumulated":
                    st_label.set_label("Accumulated")
                    st_label.add_css_class("ssh-pill-accent")
                elif status == "shadowed":
                    st_label.set_label("Shadowed")
                    st_label.add_css_class("ssh-pill-warning")
                    key_e.add_css_class("ssh-shadowed-entry")
                    val_e.add_css_class("ssh-shadowed-entry")
                elif status == "cli":
                    st_label.set_label("CLI Override")
                    st_label.add_css_class("ssh-pill-purple")
                    key_e.add_css_class("ssh-shadowed-entry")
                    val_e.add_css_class("ssh-shadowed-entry")
                elif status == "include":
                    st_label.set_label("Include")
                    st_label.add_css_class("ssh-pill-accent")
                else:
                    st_label.set_label("Inactive")
                    st_label.add_css_class("ssh-pill-muted")
                st_label.set_tooltip_text(detail)

        self._match_count_pill.set_label(f"{matched_count} matched")
        self._refresh_summary_and_right_tabs(res)

    def _refresh_summary_and_right_tabs(self, res: ResolutionResult) -> None:
        s = res.summary
        jump = s["proxy_jump"]
        cmd = f"ssh {s['user']}@{s['hostname']} -p {s['port']}" + (f" -J {jump}" if jump != "none" else "")
        self._current_ssh_cmd = cmd
        self._summary_cmd_row.set_subtitle(_esc(cmd))
        self._summary_host_row.set_subtitle(_esc(f"{s['hostname']} : {s['port']}"))
        proxy_val = jump if jump != "none" else s["proxy_command"]
        self._summary_user_row.set_subtitle(_esc(f"User: {s['user']}  |  Proxy: {proxy_val}"))
        id_files = s["identity_files"]
        if isinstance(id_files, list):
            id_txt = f"{id_files[0]} (+{len(id_files) - 1} more)" if len(id_files) > 1 else id_files[0]
        else:
            id_txt = str(id_files)
        self._summary_keys_row.set_subtitle(_esc(id_txt))

        self._refresh_effective_views()
        self._refresh_trace_view(res)
        self._refresh_raw_view()
        self._refresh_includes_view(res)

    def _refresh_effective_views(self) -> None:
        res: ResolutionResult = self._last_result
        while (child := self._eff_list.get_first_child()) is not None:
            self._eff_list.remove(child)

        query = self._eff_search.get_text().strip().lower()
        only_cfg = self._only_configured_btn.get_active()
        only_shad = self._only_shadowed_btn.get_active()

        for opt in sorted(res.effective, key=lambda o: o.key.lower()):
            lk = opt.key.lower()
            shad = res.shadowed.get(lk, [])
            if only_cfg and opt.is_default:
                continue
            if only_shad and not shad:
                continue

            val_str = ", ".join(opt.value) if isinstance(opt.value, list) else str(opt.value)
            if query and query not in lk and query not in val_str.lower():
                continue

            exp_str = ""
            if opt.expanded_value is not None:
                exp_val = ", ".join(opt.expanded_value) if isinstance(opt.expanded_value, list) else str(opt.expanded_value)
                exp_str = f"\n↳ expanded: {exp_val}"

            row: Adw.PreferencesRow
            if shad:
                exp_row = Adw.ExpanderRow(
                    title=_esc(opt.key),
                    subtitle=_esc(f"{val_str}{exp_str}"),
                )
                for sh in shad:
                    sh_row = Adw.ActionRow(
                        title=_esc(sh["value"]),
                        subtitle=_esc(f"Shadowed in {sh['source']}"),
                    )
                    jump_b = Gtk.Button(icon_name="go-jump-symbolic", valign=Gtk.Align.CENTER, tooltip_text="Jump to directive")
                    jump_b.add_css_class("flat")
                    jump_b.connect("clicked", lambda *_, bid=sh["block_id"], did=sh["dir_id"]: self._jump_to(bid, did))
                    sh_row.add_suffix(jump_b)
                    exp_row.add_row(sh_row)
                row = exp_row
            else:
                row = Adw.ActionRow(
                    title=_esc(opt.key),
                    subtitle=_esc(f"{val_str}{exp_str}"),
                )

            if opt.is_accumulated and opt.sources:
                src_btn = Gtk.Button(label=f"{len(opt.sources)} rules", valign=Gtk.Align.CENTER)
                src_btn.add_css_class("pill")
                src_btn.connect("clicked", lambda *_, bid=opt.sources[0]["block_id"], did=opt.sources[0]["dir_id"]: self._jump_to(bid, did))
                row.add_suffix(src_btn)
            elif opt.block_id:
                src_btn = Gtk.Button(label=opt.source, valign=Gtk.Align.CENTER)
                src_btn.add_css_class("flat")
                src_btn.connect("clicked", lambda *_, bid=opt.block_id, did=opt.dir_id: self._jump_to(bid, did))
                row.add_suffix(src_btn)
            else:
                src_lbl = Gtk.Label(label=opt.source, valign=Gtk.Align.CENTER)
                src_lbl.add_css_class("ssh-pill-purple" if opt.is_cli else "dim-label")
                row.add_suffix(src_lbl)

            if shad:
                sh_lbl = Gtk.Label(label=f"{len(shad)} shadowed", valign=Gtk.Align.CENTER)
                sh_lbl.add_css_class("ssh-pill")
                sh_lbl.add_css_class("ssh-pill-warning")
                row.add_suffix(sh_lbl)

            self._eff_list.append(row)

    def _refresh_trace_view(self, res: ResolutionResult) -> None:
        while (child := self._trace_list.get_first_child()) is not None:
            self._trace_list.remove(child)

        icon_map = {
            "match": "emblem-ok-symbolic",
            "skip": "media-playback-pause-symbolic",
            "warn": "dialog-warning-symbolic",
            "pass": "go-next-symbolic",
        }
        css_map = {
            "match": "ssh-trace-match",
            "warn": "ssh-trace-warn",
            "pass": "ssh-trace-pass",
        }
        for item in res.trace:
            row = Adw.ActionRow(title=_esc(item.title), subtitle=_esc(item.detail))
            row.add_prefix(Gtk.Image.new_from_icon_name(icon_map.get(item.kind, "go-next-symbolic")))
            if item.kind in css_map:
                row.add_css_class(css_map[item.kind])
            self._trace_list.append(row)

    def _refresh_raw_view(self) -> None:
        if self._raw_view.has_focus():
            return
        buf = self._raw_view.get_buffer()
        buf.set_text(serialize_config(self.blocks, self.trailing_comments))

    def _refresh_includes_view(self, res: ResolutionResult) -> None:
        # Clear dynamic rows on disk includes group
        if hasattr(self, "_disk_inc_rows"):
            for r in self._disk_inc_rows:
                self._disk_inc_group.remove(r)
        self._disk_inc_rows = []
        if res.resolved_include_files:
            for p in res.resolved_include_files:
                r = Adw.ActionRow(title=_esc(p), subtitle="Loaded &amp; evaluated")
                self._disk_inc_group.add(r)
                self._disk_inc_rows.append(r)
        else:
            r = Adw.ActionRow(title="None", subtitle="No Include files resolved for current config")
            self._disk_inc_group.add(r)
            self._disk_inc_rows.append(r)

        while (child := self._virt_inc_box.get_first_child()) is not None:
            self._virt_inc_box.remove(child)

        for vpath, vtext in self.virtual_includes.items():
            grp = Adw.PreferencesGroup(title=_esc(vpath))
            rm_btn = Gtk.Button(icon_name="user-trash-symbolic", tooltip_text="Remove virtual include")
            rm_btn.add_css_class("flat")
            rm_btn.connect("clicked", lambda *_, p=vpath: self._remove_virtual_include(p))
            grp.set_header_suffix(rm_btn)

            frame = Gtk.Frame()
            tv = Gtk.TextView(monospace=True)
            tv.set_size_request(-1, 110)
            tv.set_top_margin(8)
            tv.set_bottom_margin(8)
            tv.set_left_margin(8)
            tv.set_right_margin(8)
            tv.get_buffer().set_text(vtext)
            tv.get_buffer().connect("changed", self._on_virtual_include_changed, vpath)
            frame.set_child(tv)
            grp.add(frame)
            self._virt_inc_box.append(grp)

        d.value = entry.get_text()

        self._render_all()

    def _add_global_block(self, *_) -> None:
        if not any(b.kind == "global" for b in self.blocks):
            self.blocks.insert(0, ConfigBlock(kind="global", patterns=""))
        blk = next(b for b in self.blocks if b.kind == "global")
        self._add_directive(blk.id, "", "")

    def _add_host_block(self, *_) -> None:
        blk = ConfigBlock(
            kind="host",
            patterns="new-host",
            directives=[
                Directive(key="Hostname", value="10.0.0.10"),
                Directive(key="User", value="ubuntu"),
            ],
        )
        self.blocks.append(blk)
        self._push_history()
        self._render_all()

    def _add_match_block(self, *_) -> None:
        blk = ConfigBlock(
            kind="match",
            patterns="host *.internal user deploy",
            directives=[Directive(key="ForwardAgent", value="yes")],
        )
        self.blocks.append(blk)
        self._push_history()
        self._render_all()

    def _add_directive(self, block_id: str, key: str, value: str) -> None:
        blk = next((b for b in self.blocks if b.id == block_id), None)
        if not blk:
            return
        d = Directive(key=key, value=value)
        blk.directives.append(d)
        self._push_history()
        self._render_all()
        dw = self._dir_widgets.get(d.id)
        if dw:
            target = dw["val"] if key else dw["key"]
            target.grab_focus()  # type: ignore[attr-defined]

    def _move_block(self, idx: int, delta: int) -> None:
        nxt = idx + delta
        if 0 <= nxt < len(self.blocks):
            blk = self.blocks.pop(idx)
            self.blocks.insert(nxt, blk)
            self._push_history()
            self._render_all()

    def _toggle_block(self, blk: ConfigBlock) -> None:
        blk.disabled = not blk.disabled
        self._push_history()
        self._render_all()

    def _toggle_note(self, blk: ConfigBlock) -> None:
        if blk.id in self.editing_note_blocks and not blk.note.strip():
            self.editing_note_blocks.remove(blk.id)
        else:
            self.editing_note_blocks.add(blk.id)
        self._render_all()

    def _duplicate_block(self, idx: int) -> None:
        dup = copy.deepcopy(self.blocks[idx])
        dup.id = new_id("blk")
        dup.raw_leading_comments = []
        for d in dup.directives:
            d.id = new_id("dir")
            d.raw_leading_comments = []
        self.blocks.insert(idx + 1, dup)
        self._push_history()
        self._render_all()

    def _delete_block(self, idx: int) -> None:
        self.blocks.pop(idx)
        self._push_history()
        self._render_all()

    def _on_block_drag_motion(self, _target, _x: float, y: float, card: Gtk.ListBox) -> Gdk.DragAction:
        h = card.get_height()
        card.remove_css_class("ssh-drop-before")
        card.remove_css_class("ssh-drop-after")
        card.add_css_class("ssh-drop-before" if y < h / 2 else "ssh-drop-after")
        return Gdk.DragAction.MOVE

    def _on_block_drop(self, _target, value: str, _x: float, y: float, target_bid: str, card: Gtk.ListBox) -> bool:
        card.remove_css_class("ssh-drop-before")
        card.remove_css_class("ssh-drop-after")
        if not isinstance(value, str) or not value.startswith("block:"):
            return False
        src_bid = value.split(":", 1)[1]
        if src_bid == target_bid:
            return False
        src_idx = next((i for i, b in enumerate(self.blocks) if b.id == src_bid), -1)
        if src_idx < 0:
            return False
        moved = self.blocks.pop(src_idx)
        tgt_idx = next((i for i, b in enumerate(self.blocks) if b.id == target_bid), len(self.blocks))
        before = y < card.get_height() / 2
        self.blocks.insert(tgt_idx if before else tgt_idx + 1, moved)
        self._push_history()
        self._render_all()
        return True

    def _on_dir_drag_motion(self, _target, _x: float, y: float, row: Gtk.ListBoxRow) -> Gdk.DragAction:
        h = row.get_height()
        row.remove_css_class("ssh-drop-before")
        row.remove_css_class("ssh-drop-after")
        row.add_css_class("ssh-drop-before" if y < h / 2 else "ssh-drop-after")
        return Gdk.DragAction.MOVE

    def _on_dir_drop(
        self, _target, value: str, _x: float, y: float, tgt_bid: str, tgt_did: str | None, row: Gtk.ListBoxRow
    ) -> bool:
        row.remove_css_class("ssh-drop-before")
        row.remove_css_class("ssh-drop-after")
        if not isinstance(value, str) or not value.startswith("dir:"):
            return False
        _, src_bid, src_did = value.split(":", 2)
        if src_did == tgt_did:
            return False
        src_blk = next((b for b in self.blocks if b.id == src_bid), None)
        tgt_blk = next((b for b in self.blocks if b.id == tgt_bid), None)
        if not src_blk or not tgt_blk:
            return False
        s_idx = next((i for i, d in enumerate(src_blk.directives) if d.id == src_did), -1)
        if s_idx < 0:
            return False
        moved = src_blk.directives.pop(s_idx)
        if tgt_did is None:
            tgt_blk.directives.append(moved)
        else:
            t_idx = next((i for i, d in enumerate(tgt_blk.directives) if d.id == tgt_did), len(tgt_blk.directives))
            before = y < row.get_height() / 2
            tgt_blk.directives.insert(t_idx if before else t_idx + 1, moved)
        self._push_history()
        self._render_all()
        return True

    def _jump_to(self, block_id: str | None, dir_id: str | None) -> None:
        target_widget = (
            self._dir_widgets.get(dir_id or "", {}).get("row")
            or self._block_widgets.get(block_id or "", {}).get("card")
        )
        if not isinstance(target_widget, Gtk.Widget):
            return
        target_widget.grab_focus()
        target_widget.add_css_class("ssh-flash")
        GLib.timeout_add(1400, lambda: target_widget.remove_css_class("ssh-flash") and False)

    def _on_verify_system_ssh_g(self, *_) -> None:
        with tempfile.NamedTemporaryFile("w", suffix=".conf", delete=False, encoding="utf-8") as tmp:
            tmp.write(self.get_config_text())
            tmp_path = Path(tmp.name)
        try:
            ok, output = run_system_ssh_g(
                self._sim.raw_target,
                config_path=tmp_path,
                cli_port=self._sim.cli_port,
                cli_user=self._sim.cli_user,
            )
        finally:
            tmp_path.unlink(missing_ok=True)

        self._show_text_dialog(
            "System `ssh -G` Output" if ok else "System `ssh -G` Error",
            output,
        )

        path = file_obj.get_path()
        if path:
            self.load_file(path)
            return True
        return False

    def prompt_open_file(self) -> None:
        dialog = Gtk.FileDialog(title="Open SSH Configuration")
        ssh_dir = Path.home() / ".ssh"
        if ssh_dir.exists():
            dialog.set_initial_folder(Gio.File.new_for_path(str(ssh_dir)))
        root = self.get_root()
        parent = root if isinstance(root, Gtk.Window) else None
        dialog.open(parent, None, self._finish_open_file)

    def _finish_open_file(self, dialog: Gtk.FileDialog, result: Gio.AsyncResult) -> None:
        try:
            gfile = dialog.open_finish(result)
            if gfile and (p := gfile.get_path()):
                self.load_file(p)
        except GLib.Error:
            pass

    def prompt_save_file(self) -> None:
        dialog = Gtk.FileDialog(title="Save SSH Configuration", initial_name="config")
        if self.current_file:
            dialog.set_initial_file(Gio.File.new_for_path(str(self.current_file)))
        else:
            ssh_dir = Path.home() / ".ssh"
            if ssh_dir.exists():
                dialog.set_initial_folder(Gio.File.new_for_path(str(ssh_dir)))
        root = self.get_root()
        parent = root if isinstance(root, Gtk.Window) else None
        dialog.save(parent, None, self._finish_save_file)

    def _finish_save_file(self, dialog: Gtk.FileDialog, result: Gio.AsyncResult) -> None:
        try:
            gfile = dialog.save_finish(result)
            if gfile and (p := gfile.get_path()):
                self.save_to_file(p)
        except GLib.Error:
            pass

    def _present_modal(
        self, title: str, body: Gtk.Widget, *, action_label: str | None = None, on_action=None
    ) -> None:
        if hasattr(Adw, "Dialog"):
            dlg = Adw.Dialog(title=title, content_width=620, content_height=460)
            tv_view = Adw.ToolbarView()
            hb = Adw.HeaderBar()
            if action_label and on_action:
                btn = Gtk.Button(label=action_label)
                btn.add_css_class("suggested-action")
                btn.connect("clicked", lambda *_: on_action(dlg))
                hb.pack_end(btn)
            tv_view.add_top_bar(hb)
            tv_view.set_content(body)
            dlg.set_child(tv_view)
            dlg.present(self)
        else:
            win = Adw.Window(title=title, default_width=620, default_height=460, modal=True)
            root = self.get_root()
            if isinstance(root, Gtk.Window):
                win.set_transient_for(root)
            tv_view = Adw.ToolbarView()
            hb = Adw.HeaderBar()
            if action_label and on_action:
                btn = Gtk.Button(label=action_label)
                btn.add_css_class("suggested-action")
                btn.connect("clicked", lambda *_: on_action(win))
                hb.pack_end(btn)

            win.set_content(tv_view)
            win.present()

    # ------------------------------------------------------------------
    # History & Refresh
    # ------------------------------------------------------------------
    def _push_history(self) -> None:
        snap = (copy.deepcopy(self.blocks), list(self.trailing_comments))
        self._history = self._history[: self._history_idx + 1]
        self._history.append(snap)
        if len(self._history) > 60:
            self._history.pop(0)
        self._history_idx = len(self._history) - 1
        self._emit_history()
        self.emit("changed")

    def _emit_history(self) -> None:
        self.emit("history-changed", self.can_undo(), self.can_redo())

    def _render_all(self) -> None:
        self._render_blocks()
        self._render_quick_hosts()
        self._update_resolution()

review on above:

I successfully accessed and reviewed both uploaded files: the HTML prototype (`ai_studio_code.html`) and the proposed Python/GTK4 implementation (`advanced-ssh-config-editor.txt`).

## **Overall assessment**

**The concept is strong, and I think it could become one of SSH Pilot's most valuable configuration features. However, I would not integrate the proposed implementation as-is.**

The two-pane design addresses the central problem with advanced OpenSSH configurations: users need to understand not just *what rules exist*, but *which rules actually apply to a connection and why*.

The most valuable aspects are:

- **Ordered configuration blocks:** `Host`, `Match`, and global settings are visible in their actual order.
- **Live effective configuration:** Users can select a host and see which options win.
- **Precedence explanations:** Applied and shadowed directives are identified.
- **Configuration trace:** Users can understand how rules interact.
- **Raw configuration view:** Advanced users aren't forced to abandon standard OpenSSH syntax.
- **GTK4/libadwaita implementation:** The proposed widget fits SSH Pilot's existing technology choices.

The architecture has the right broad idea:

**Editable OpenSSH configuration**

Ordered Host / Match blocks, directives and Include files

**Rule analysis**

Matches, precedence, provenance

**Effective SSH settings**

OpenSSH-verified values

The main problem is that the supplied Python engine attempts to reproduce OpenSSH's evaluation behavior. Its results are not reliably equivalent to OpenSSH, and some editor operations can change the meaning of the configuration.

## **Problems I found in the implementation**

| Severity | Finding                                                                        | Consequence                                                                             |
| -------- | ------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------- |
| Critical | Global blocks can be moved below `Host` blocks                                 | The simulator and saved configuration disagree about which hosts receive those settings |
| Critical | Saving replaces symbolic links                                                 | Can break NixOS/Home Manager-managed SSH configurations                                 |
| Critical | Custom resolution engine is not OpenSSH-equivalent                             | Incorrect effective settings, particularly for `Match`, canonicalization and defaults   |
| High     | Generated SSH command uses the resolved hostname instead of the original alias | Can bypass the intended `Host` rules                                                    |
| High     | Verification runs `ssh -G` using a temporary `-F` file                         | Does not establish parity with the actual launch environment                            |
| High     | Repeated resolution and filesystem access run synchronously                    | Potential GTK main-thread stalls                                                        |
| High     | Virtual Include editor rebuilds itself during text changes                     | Can disrupt editing and focus                                                           |
| High     | Saving rewrites the entire configuration                                       | Formatting changes and possible conflicts with external edits                           |

### **Two bugs I reproduced**

**1. Global block semantics**

The editor allows this block sequence:

```
Host zoo
    User admin

# Global block inserted here by the editor
Port 2200

Host bar
    HostName example.com
```

Its Python resolver considers `Port 2200` global and applies it to `bar`.

But in the serialized OpenSSH configuration, `Port 2200` belongs to `Host zoo`. OpenSSH does not have a special global-block delimiter.

This makes the editor unsafe for arbitrary block reordering.

**2. Symbolic-link destruction**

I tested `save_config_safely()` with a symbolic link pointing to an SSH configuration file.

After saving, the symbolic link had been replaced with a regular file, while the original target remained unchanged.

For SSH Pilot, given its support for configurations managed externally, this is a release-blocking issue.

I also tested:

```
Match exec "false"
    User root
```

The proposed simulator reported `User root` as active because its default simulated `Match exec` result is true. That illustrates why its output cannot be presented as authoritative.

## **How I would improve the design**

I would preserve the two-pane concept, but make the interface less dense.

The left pane should primarily show the ordered configuration structure, with compact, expandable rules. The right pane should show the selected rule's options and the actual resulting configuration for a chosen host.

Most importantly, I would separate **configuration editing**, **OpenSSH resolution**, and **explanation** into independent components.

OpenSSH should be authoritative for effective settings. A separate analyzer can explain which blocks probably contributed, trace precedence, and identify conflicts. Whenever that explanation is uncertain, the interface should say so rather than claiming a rule was definitively applied or shadowed.

For SSH Pilot specifically, I would also reuse its existing configuration handling instead of introducing a second independent implementation that must remain compatible with every OpenSSH behavior and future SSH Pilot change.

The Python package provides a reasonable starting UI structure, but I would replace the parser, resolver and save infrastructure before integration.

## **Verdict**

Product concept

# **8/10**

Worth developing

Implementation readiness

# **4/10**

Needs substantial engineering

My recommendation is to **keep the interaction model and redesign the underlying engine around strict OpenSSH parity**.

I also think this could justify a standalone application, rather than being exclusively an SSH Pilot feature. A visual OpenSSH configuration editor with reliable precedence explanations, safe editing and live resolution could be useful independently.

The Python engine imported successfully, and the GTK widget and app code passed Python syntax compilation. I did not execute the GTK interface or verify it against a live OpenSSH installation, so this is a source-level review with targeted engine tests, not a complete runtime audit.
