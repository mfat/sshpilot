# نکات استفاده از SSH Pilot
#
# هر نکته در یک سطر. سطرهای خالی و سطرهایی که با «#» شروع می‌شوند نادیده گرفته می‌شوند.
# از {primary} برای کلید تغییردهنده اصلی استفاده کنید (Ctrl در لینوکس/ویندوز، ⌘ در مک).
# برچسب‌های اختیاری در ابتدای سطر نمایش را کنترل می‌کنند:
#   [file-manager] — فقط زمانی که مدیر فایل درون‌برنامه‌ای در دسترس است
#   [external-terminal] — فقط زمانی که گزینه‌های ترمینال خارجی نمایش داده می‌شوند

[file-manager] یک میزبان را انتخاب کرده و {primary}+Shift+O را فشار دهید تا مدیر فایل باز شود
برای جستجوی اتصالات خود، {primary}+F را فشار دهید
برای باز کردن اتصال جدید، {primary}+Shift+N را فشار دهید
برای جستجو درون ترمینال، {primary}+Shift+F را فشار دهید
برای کپی کلید SSH خود به سرور، {primary}+Shift+K را فشار دهید
برای تغییر وضعیت نوار کناری، F9 را فشار دهید
برای مشاهده همه میانبرهای صفحه‌کلید، {primary}+? را فشار دهید
کلیک وسط روی یک اتصال برای باز کردن آن در یک زبانه جدید
کلیک وسط روی یک گروه برای باز کردن تمام اتصالات آن در زبانه‌ها
کلیک وسط روی یک زبانه برای بستن آن
[file-manager] نشانگر را روی اتصال ببرید تا «مدیریت فایل‌ها» نمایش داده شود
[external-terminal] ترمینال مورد نظر خود را در تنظیمات انتخاب کنید
دوبار کلید Shift را بزنید تا میزبان‌ها را جستجو کرده و به یک اتصال بروید
