# Nutzungstipps für SSH Pilot
#
# Ein Tipp pro Zeile. Leere Zeilen und Zeilen, die mit "#" beginnen, werden ignoriert.
# {primary} steht für den Plattform-Modifikator (Strg unter Linux/Windows, ⌘ unter macOS).
# Optionale Tags am Zeilenanfang steuern die Sichtbarkeit:
#   [file-manager] — nur wenn der integrierte Dateimanager verfügbar ist
#   [external-terminal] — nur wenn externe Terminal-Optionen angezeigt werden
# Diese Datei ist die deutsche Fassung von tips.md — Tipps können hier bearbeitet,
# ergänzt oder entfernt werden, ohne den Quelltext zu ändern.

[file-manager] Wählen Sie einen Host aus und drücken Sie {primary}+Umschalt+O, um den Dateimanager zu öffnen
Drücken Sie {primary}+F, um Ihre Verbindungen zu durchsuchen
Drücken Sie {primary}+Umschalt+N, um eine neue Verbindung zu öffnen
Drücken Sie {primary}+Umschalt+F, um im Terminal zu suchen
Drücken Sie {primary}+Umschalt+K, um Ihren SSH-Schlüssel auf einen Server zu kopieren
Drücken Sie F9, um die Seitenleiste ein- oder auszublenden
Drücken Sie {primary}+?, um alle Tastenkürzel anzuzeigen
Mittlerer Klick auf eine Verbindung öffnet sie in einem neuen Tab
Mittlerer Klick auf eine Gruppe öffnet alle Verbindungen in Tabs
Mittlerer Klick auf einen Tab schließt ihn
[file-manager] Zeigen Sie auf eine Verbindung, um Dateien verwalten einzublenden
[external-terminal] Wählen Sie in den Einstellungen Ihr bevorzugtes Terminal
Zweimal Umschalt tippen, um Hosts zu suchen und eine Verbindung zu öffnen
