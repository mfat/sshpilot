# Dicas de uso do SSH Pilot
#
# Uma dica por linha. Linhas em branco e iniciadas por "#" são ignoradas.
# Use {primary} para a tecla modificadora principal (Ctrl no Linux/Windows, ⌘ no macOS).
# Tags opcionais no início controlam a visibilidade:
#   [file-manager] — apenas quando o gerenciador de arquivos integrado estiver disponível
#   [external-terminal] — apenas quando as opções de terminal externo forem exibidas

[file-manager] Selecione um host e pressione {primary}+Shift+O para abrir o gerenciador de arquivos
Pressione {primary}+F para pesquisar suas conexões
Pressione {primary}+Shift+N para abrir uma nova conexão
Pressione {primary}+Shift+F para pesquisar no terminal
Pressione {primary}+Shift+K para copiar sua chave SSH para um servidor
Pressione F9 para alternar a barra lateral
Pressione {primary}+? para ver todos os atalhos de teclado
Clique com o botão do meio em uma conexão para abri-la em uma nova aba
Clique com o botão do meio em um grupo para abrir todas as suas conexões em abas
Clique com o botão do meio em uma aba para fechá-la
[file-manager] Passe o cursor sobre uma conexão para exibir Gerenciar arquivos
[external-terminal] Escolha seu terminal preferido nas Preferências
Pressione Shift duas vezes para pesquisar hosts e ir para uma conexão
