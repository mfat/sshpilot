# Astuces d’utilisation de sshPilot
#
# Une astuce par ligne. Les lignes vides ou commençant par « # » sont ignorées.
# Modifiez, ajoutez ou supprimez des astuces ici — inutile de modifier le code source de l’application.

Sélectionnez un hôte et appuyez sur Ctrl+Shift+O pour ouvrir le gestionnaire de fichiers !
Appuyez sur Ctrl+F pour rechercher parmi les connexions
Appuyez sur Ctrl+Shift+N pour ouvrir une nouvelle connexion
Appuyez sur Ctrl+Shift+F pour rechercher dans le terminal
Appuyez sur Ctrl+Shift+K pour copier la clé SSH sur un serveur
Appuyez sur F9 pour afficher ou masquer la barre latérale
Appuyez sur Ctrl+? pour afficher tous les raccourcis clavier
Cliquez avec le bouton central sur une connexion pour l’ouvrir dans un nouvel onglet !
Cliquez avec le bouton central sur un onglet pour le fermer !
Survolez la partie droite d’une connexion pour accéder au gestionnaire de fichiers
Choisissez le terminal à utiliser dans les paramètres
Au démarrage, il suffit de saisir un nom d’hôte et d’appuyer sur Enter pour se connecter !
