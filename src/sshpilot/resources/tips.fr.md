# Astuces d’utilisation de SSH Pilot
#
# Une astuce par ligne. Les lignes vides ou commençant par « # » sont ignorées.
# Utilisez {primary} pour le modificateur de plateforme (Ctrl sous Linux/Windows, ⌘ sous macOS).
# Des balises optionnelles en début de ligne contrôlent la visibilité :
#   [file-manager] — uniquement si le gestionnaire de fichiers intégré est disponible
#   [external-terminal] — uniquement si les options de terminal externe sont affichées

[file-manager] Sélectionnez un hôte et appuyez sur {primary}+Shift+O pour ouvrir le gestionnaire de fichiers
Appuyez sur {primary}+F pour rechercher parmi les connexions
Appuyez sur {primary}+Shift+N pour ouvrir une nouvelle connexion
Appuyez sur {primary}+Shift+F pour rechercher dans le terminal
Appuyez sur {primary}+Shift+K pour copier la clé SSH sur un serveur
Appuyez sur F9 pour afficher ou masquer la barre latérale
Appuyez sur {primary}+? pour afficher tous les raccourcis clavier
Clic du milieu sur une connexion pour l’ouvrir dans un nouvel onglet
Clic du milieu sur un groupe pour ouvrir toutes ses connexions dans des onglets
Clic du milieu sur un onglet pour le fermer
[file-manager] Survolez une connexion pour afficher le gestionnaire de fichiers
[external-terminal] Choisissez votre terminal préféré dans les paramètres
Appuyez deux fois sur Maj pour rechercher des hôtes et ouvrir une connexion
