# Советы по использованию SSH Pilot
#
# Один совет на строку. Пустые строки и строки, начинающиеся с «#», игнорируются.
# Используйте {primary} для обозначения основной клавиши-модификатора (Ctrl в Linux/Windows, ⌘ в macOS).
# Необязательные теги в начале строки управляют видимостью:
#   [file-manager] — только когда доступен встроенный диспетчер файлов
#   [external-terminal] — только когда отображаются параметры внешнего терминала

[file-manager] Выберите хост и нажмите {primary}+Shift+O, чтобы открыть диспетчер файлов
Нажмите {primary}+F для поиска по подключениям
Нажмите {primary}+Shift+N, чтобы открыть новое подключение
Нажмите {primary}+Shift+F для поиска в терминале
Нажмите {primary}+Shift+K, чтобы скопировать ваш SSH-ключ на сервер
Нажмите F9, чтобы скрыть или показать боковую панель
Нажмите {primary}+?, чтобы просмотреть все комбинации клавиш
Нажмите среднюю кнопку мыши на подключении, чтобы открыть его в новой вкладке
Нажмите среднюю кнопку мыши на группе, чтобы открыть все её подключения во вкладках
Нажмите среднюю кнопку мыши на вкладке, чтобы закрыть её
[file-manager] Наведите курсор на подключение, чтобы отобразить «Управление файлами»
[external-terminal] Выберите предпочитаемый терминал в Настройках
Дважды нажмите Shift для поиска хостов и перехода к подключению
