# SSH Pilot usage tips
#
# One tip per line. Blank lines and lines starting with "#" are ignored.
# Use {primary} for the platform modifier (Ctrl on Linux/Windows, ⌘ on macOS).
# Optional leading tags gate visibility:
#   [file-manager] — only when the in-app file manager is available
#   [external-terminal] — only when external terminal options are shown

[file-manager] Select a host, press {primary}+Shift+O to open the file manager
Press {primary}+F to search your connections
Press {primary}+Shift+N to open a new connection
Press {primary}+Shift+F to search inside the terminal
Press {primary}+Shift+K to copy your SSH key to a server
Press F9 to toggle the sidebar
Press {primary}+? to see all keyboard shortcuts
Middle-click a connection to open it in a new tab
Middle-click a group to open all its connections in tabs
Middle-click a tab to close it
[file-manager] Hover a connection to reveal Manage Files
[external-terminal] Choose your preferred terminal in Settings
Double-tap Shift to search hosts and jump to a connection
