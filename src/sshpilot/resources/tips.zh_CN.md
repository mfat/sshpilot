# SSH Pilot 使用技巧
#
# 每行一条技巧。空白行和以“#”开头的行将被忽略。
# 使用 {primary} 表示平台主修饰键（Linux/Windows 上为 Ctrl，macOS 上为 ⌘）。
# 开头的可选标签用于控制可见性：
#   [file-manager] — 仅在内置文件管理器可用时显示
#   [external-terminal] — 仅在显示外部终端选项时显示

[file-manager] 选择主机后按 {primary}+Shift+O 打开文件管理器
按 {primary}+F 搜索您的连接
按 {primary}+Shift+N 打开新连接
按 {primary}+Shift+F 在终端内搜索
按 {primary}+Shift+K 将 SSH 密钥复制到服务器
按 F9 显示或隐藏侧边栏
按 {primary}+? 查看所有键盘快捷键
在连接上点击鼠标中键可在新标签页中打开
在分组上点击鼠标中键可在标签页中打开其所有连接
在标签页上点击鼠标中键可将其关闭
[file-manager] 将鼠标悬停在连接上可显示“管理文件”
[external-terminal] 在“首选项”中选择您偏好的终端
双击 Shift 键可搜索主机并跳转至连接
