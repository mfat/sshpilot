# Consejos de uso de SSH Pilot
#
# Un consejo por línea. Las líneas en blanco y las que comienzan con "#" se ignoran.
# Use {primary} para la tecla modificadora principal (Ctrl en Linux/Windows, ⌘ en macOS).
# Etiquetas opcionales al inicio controlan la visibilidad:
#   [file-manager] — solo cuando el gestor de archivos integrado está disponible
#   [external-terminal] — solo cuando se muestran opciones de terminal externa

[file-manager] Seleccione un host y pulse {primary}+Shift+O para abrir el gestor de archivos
Pulse {primary}+F para buscar sus conexiones
Pulse {primary}+Shift+N para abrir una nueva conexión
Pulse {primary}+Shift+F para buscar dentro del terminal
Pulse {primary}+Shift+K para copiar su clave SSH a un servidor
Pulse F9 para alternar la barra lateral
Pulse {primary}+? para ver todos los atajos de teclado
Clic central en una conexión para abrirla en una pestaña nueva
Clic central en un grupo para abrir todas sus conexiones en pestañas
Clic central en una pestaña para cerrarla
[file-manager] Pase el cursor sobre una conexión para mostrar Gestionar archivos
[external-terminal] Elija su terminal preferido en Preferencias
Pulse dos veces Shift para buscar hosts e ir a una conexión
