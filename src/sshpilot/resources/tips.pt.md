# Dicas de utilização do SSH Pilot
#
# Uma dica por linha. Linhas em branco e iniciadas por "#" são ignoradas.
# Utilize {primary} para a tecla modificadora principal (Ctrl em Linux/Windows, ⌘ em macOS).
# Etiquetas opcionais no início controlam a visibilidade:
#   [file-manager] — apenas quando o gestor de ficheiros integrado estiver disponível
#   [external-terminal] — apenas quando as opções de terminal externo forem apresentadas

[file-manager] Selecione um anfitrião e prima {primary}+Shift+O para abrir o gestor de ficheiros
Prima {primary}+F para pesquisar as suas ligações
Prima {primary}+Shift+N para abrir uma nova ligação
Prima {primary}+Shift+F para pesquisar no terminal
Prima {primary}+Shift+K para copiar a sua chave SSH para um servidor
Prima F9 para alternar a barra lateral
Prima {primary}+? para ver todos os atalhos de teclado
Clique com o botão do meio numa ligação para abri-la num novo separador
Clique com o botão do meio num grupo para abrir todas as suas ligações em separadores
Clique com o botão do meio num separador para fechá-lo
[file-manager] Passe o cursor sobre uma ligação para revelar Gerir ficheiros
[external-terminal] Escolha o seu terminal preferido nas Preferências
Prima duas vezes Shift para pesquisar anfitriões e saltar para uma ligação
